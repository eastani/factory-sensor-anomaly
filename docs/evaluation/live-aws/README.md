# Live AWS deployment — captured evidence

Snapshot of the production AWS deployment taken **2026-05-17** while local
ingester + scorer workers fed real traffic into the App Runner instance.
The stack was torn down with `make cloud-down-aws` immediately afterwards
to stop billing; this directory is the durable record.

## Stack

| Component | Resource | Notes |
|-----------|----------|-------|
| API | AWS App Runner `factory-sensor-anomaly` | 0.25 vCPU / 0.5 GB, VPC-connected |
| Database | RDS PostgreSQL 16.14 `db.t4g.micro` | `publicly_accessible=false` |
| Image registry | ECR `factory-sensor-anomaly` | scan-on-push, lifecycle keeps 10 latest |
| Secret | Secrets Manager `factory-sensor-anomaly/db-url` | JSON of `POSTGRES_*` env vars |
| Auth (CI → AWS) | IAM OIDC + role `factory-sensor-anomaly-github-deploy` | Trust scoped to `refs/heads/main` |
| State | S3 `factory-sensor-anomaly-tfstate-601753496304` + DynamoDB locks | Versioned, AES256 |

11 inference rows persisted (`anomalies.json`) — matches the `/infer` 2xx

## What this evidence proves

- The Docker image built in CI runs unchanged on a managed-container service.
- OIDC-only authentication from GitHub Actions works end-to-end —
  no static AWS credentials live anywhere on disk or in GitHub Secrets.
- The Postgres connection from App Runner through the VPC connector to a
  private RDS instance is functional (the `db: ok` value in `healthz.json`
  is generated by a real `SELECT 1`).
- The Prometheus middleware label-cardinality strategy holds — every label
  in `metrics.txt` is bounded (no raw `machine_id` leaking into HTTP labels).
- The baseline model loaded on startup is the one baked into the image at
  build time (`model_version=baked-20260516-235813`); a fresh image rebuild
  yields a fresh version.

## Reproducing

```bash
cd infra/bootstrap-aws && terraform apply           # one-time, $0 idle
# Push to main, or trigger:
gh workflow run deploy-aws.yml
# Tear down:
make cloud-down-aws
```

Approximate steady-state cost while running: **~$40/month**
(App Runner ~$25 + RDS db.t4g.micro ~$13 + everything else negligible).
